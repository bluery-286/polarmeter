PolarMeter 개인정보처리방침

시행일: 2026-07-13

이 문서는 PolarMeter V1-04 Android/iOS RC 및 초기 스토어 제출 준비 기준으로 작성되었습니다.

1. 서비스 개요

PolarMeter는 미국장과 국내장의 시장 환경을 온도처럼 요약해 보여주는 시장 브리핑 앱입니다.

PolarMeter는 투자 권유, 거래 지시, 개인 맞춤형 금융 자문, 수익 보장을 제공하지 않습니다.

2. 수집하는 개인정보

V1-04 RC 기준 PolarMeter 앱은 사용자의 개인정보를 직접 수집하지 않습니다.

현재 앱이 직접 수집하지 않는 정보는 다음과 같습니다.

  • 이름, 이메일, 전화번호 등 식별 정보
  • 증권 계좌, 포트폴리오, 거래 내역
  • 결제 정보
  • 위치 정보
  • 연락처, 사진, 마이크, 카메라 데이터
  • 광고 식별자 또는 맞춤형 광고용 정보

향후 로그인, 알림, 관심종목, 유료 기능, 문의 기능 등을 도입하는 경우 수집 항목과 이용 목적을 별도로 고지하고 필요한 동의를 받겠습니다.

3. 네트워크에서 자동으로 처리될 수 있는 정보

V1-04 RC 기준 PolarMeter는 다음 SDK를 포함하지 않습니다.

  • 광고 SDK 없음
  • 결제 SDK 없음
  • 증권사/브로커리지 계정 연결 없음
  • 외부 분석 SDK 없음

앱은 시장 브리핑용 공개 캐시 파일을 가져오기 위해 polarmeter.polarbearworks.com에 암호화된 HTTPS 요청을 보냅니다. 운영자는 이 요청으로 사용자를 식별하거나 행동을 추적하지 않습니다. 다만 호스팅·콘텐츠 전송·네트워크 제공자는 서비스 제공과 보안을 위해 IP 주소, 접속시각, 사용자 에이전트 같은 기본 접속 정보를 일시적으로 처리할 수 있으며, 해당 제공자의 정책이 적용됩니다.

Google Play, Apple TestFlight/App Store, 운영체제 제공자는 앱 배포와 오류 대응에 필요한 기본 진단 정보나 사용 정보를 처리할 수 있습니다. 이 정보는 각 제공자의 개인정보 처리방침을 따릅니다.

PolarMeter는 자체 서버로 사용자를 식별할 수 있는 정보를 전송하지 않습니다.

뉴스 원문 링크를 누르면 외부 브라우저와 해당 언론사 사이트가 열리며, 이후 처리는 해당 사이트의 개인정보처리방침을 따릅니다.

4. 기기 내 저장

PolarMeter는 온보딩 확인 여부, 테마 선택, 최근 브리핑 기록을 사용자 기기 안에만 저장합니다. 이 정보는 PolarMeter 서버로 전송하거나 계정과 동기화하지 않습니다.

사용자는 앱 데이터 삭제 또는 앱 제거를 통해 기기 내 저장 정보를 삭제할 수 있습니다.

5. 이용 목적

현재 PolarMeter가 직접 수집하는 개인정보가 없으므로 별도 개인정보 이용 목적도 없습니다.

향후 기능 확장으로 개인정보를 처리하게 되는 경우 다음 목적 범위 안에서 최소한으로 처리합니다.

  • 알림 제공
  • 고객 문의 대응
  • 법령 또는 스토어 정책 준수

V1-04 RC 기준 PolarMeter는 개인정보를 제3자에게 제공하지 않으며, 개인정보 처리 업무를 외부 업체에 위탁하지 않습니다.
